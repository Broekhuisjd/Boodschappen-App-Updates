# Boodschappen-app – Android-updates

Openbare downloadlocatie voor toekomstige Android-versies. Broncode, boodschappenlijsten en Supabase-gegevens worden hier niet gepubliceerd.

**Status:** er is nog geen APK-release gepubliceerd. Een release volgt pas na een geslaagde build en verificatie van de Android-ondertekening.

De app controleert GitHub Releases via `https://api.github.com/repos/Broekhuisjd/Boodschappen-App-Updates/releases/latest`.

**Let op:** updates over de bestaande installatie vereisen dezelfde applicationId en dezelfde ondertekeningssleutel. Verwijder de bestaande app niet voordat de migratie is gecontroleerd.
